**TaskNotes App: your tasks on the web, iPhone and Android.** It works with the same Markdown task notes as this plugin. [Open TaskNotes App](https://app.tasknotes.dev/) · [Get it for iPhone](https://apps.apple.com/app/tasknotes/id6797168033) · [Get it for Android](https://play.google.com/store/apps/details?id=dev.tasknotes.app) · [Setup guide](https://tasknotes.dev/guides/tasknotes-app/). To use it with the tasks in this vault, see **Settings → TaskNotes → TaskNotes App**.
