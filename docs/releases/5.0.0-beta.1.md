# TaskNotes 5.0.0-beta.1

> [!info] TaskNotes v5 beta
>
> TaskNotes v5 remains an opt-in beta. TaskNotes 4.12.4 is the recommended
> stable release. Please use a backed-up vault and
> [report problems](https://github.com/callumalpass/tasknotes/issues).

## Changed

- TaskNotes now automatically upgrades unmodified TaskNotes-generated mdbase
  v0.2 collection metadata to the canonical v0.3 task type and contract when
  the integration is enabled. Existing task notes are not rewritten, custom
  collection settings are preserved, and the previous metadata is backed up.
  Ambiguous, interrupted, or failed upgrades are safely restored or left for
  manual review. See
  [Integrations Settings](https://tasknotes.dev/settings/integrations/#mdbase).
- This beta includes the fixes and compatibility improvements released in
  [4.12.1](https://github.com/callumalpass/tasknotes/releases/tag/4.12.1),
  [4.12.2](https://github.com/callumalpass/tasknotes/releases/tag/4.12.2),
  [4.12.3](https://github.com/callumalpass/tasknotes/releases/tag/4.12.3), and
  [4.12.4](https://github.com/callumalpass/tasknotes/releases/tag/4.12.4).
