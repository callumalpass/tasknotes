# TaskNotes 5.0.0-beta.6

> [!info] TaskNotes v5 beta
>
> This is an opt-in beta. TaskNotes 4.14.0 remains the recommended stable release.

## Before updating

- Requires Obsidian 1.13.1 or newer. Back up the complete vault and finish syncing before updating. See the [v4 to v5 upgrade guide](https://tasknotes.dev/migration-v4-to-v5/) for metadata upgrades, recovery and returning to v4.
- This beta brings the v5 line up to date with main through 4.14.0 while retaining v5's mdbase metadata and settings. Existing Base files are not rewritten automatically.
- The beta.5 precautions still apply: avoid simultaneous metadata upgrades on other devices, and keep an independent full-vault backup. TaskNotes App setup still requires its separate consent.

## Added

- (#2412) Recurring task checkoffs show the completed occurrence and next date, including the year, with an Undo action. Undo restores the affected occurrence and schedule without overwriting later unrelated edits. Materialized occurrence notes are retained when undone. Thanks to @PaulSnyder for the suggestion. See [Recurring Tasks](https://tasknotes.dev/features/recurring-tasks/#completion-tracking).
- (#2413) Reminders missed while Obsidian was closed are shown at startup, up to 24 hours back. Only the latest missed reminder per task is shown; more than three tasks are combined into a summary. Catch-up waits for notes still being indexed, and messages use the selected language. Thanks to @aliceinblunderland0 for the suggestion. See [Task Reminders](https://tasknotes.dev/features/reminders/#delivery-and-sleep).
- (#2404) Added an opt-in **Enter saves task** setting for natural language task creation. Shift+Enter inserts a newline and Ctrl/Cmd+Enter still saves. Enter accepts a visible autocomplete suggestion instead of saving and does not save while confirming IME text. Thanks to @k4zcho for contributing this. See [Natural Language Processing](https://tasknotes.dev/settings/features/#natural-language-processing).
- (#2375) All-day Google Calendar task exports can be shown as Free rather than blocking availability. The option is off by default; timed exports remain Busy. Run **Sync all tasks** to update existing events. Thanks to @szatzger for the suggestion. See [Calendar Integration](https://tasknotes.dev/features/calendar-integration/#google-calendar-task-availability).
- (#2326) Added a tracking status-bar stop button and a **Stop active time tracking** command. One active tracker stops directly; multiple trackers prompt for a choice. Thanks to @sumiyalairu03 for the suggestion and @kjohnsen for the command-palette follow-up. See [Time Management](https://tasknotes.dev/features/time-management/#stop-an-active-tracker-without-opening-its-note).

## Changed

- (#2381) Task List group and subgroup moves no longer require manual-order sorting. Drops preview property changes, while reordering uses a separate insertion line. The movement handle offers a destination menu and manual-order **Move up/down** actions. Property moves offer Undo while preserving later unrelated edits. A separate **Add as subtask** target preserves existing project memberships, group values and manual rank; self-assignment and cycles are blocked. List-valued moves show before/after values, and dropping on the original row cancels the move. Thanks to @iantierney for the suggestion. See [Task List](https://tasknotes.dev/views/task-list/).
- (#2401, #2400) Task modal status icons now match task cards, and empty Kanban cells no longer display a decorative plus that looks like an add button. Thanks to @iantierney for reporting both issues.

## Fixed

- Fixed recurring completion Undo incorrectly reporting a conflict when a task relies on the default status instead of an explicit YAML status. Undo preserves the omitted property and the runtime default, including custom status-property mappings.
- (#2415) Fixed manual drag-reordering of exactly two ranked tasks in descending Task List groups not persisting the intended order. Rank computation now uses the view's configured sort direction, including descending Kanban ordering. Thanks to @paladinm078 for the beta.5 report and precise reproduction.
- (#2411) Google calendars display user-set names instead of original feed titles for subscribed and URL-added calendars. Thanks to @Alireza-RS for reporting.
- (#2328) Completing or skipping a timed materialized occurrence now records its date on the recurring parent and advances the schedule, whether changed through Properties, a card or another plugin. Thanks to @mudnug for reporting and following up.
- (#2409) Recorded time entries remain visible when they span a week or another calendar date-range boundary. Thanks to @RumiaKitinari for reporting.
- (#2408) Localized Modal Fields controls, labels, type badges, notices and reset confirmation. Saved field and group names are unchanged. Thanks to @WangJingJun-dev for contributing the fix.
- Fixed status autocomplete being hidden by the editor's automatically paired closing `*`, so Enter selects the suggested status instead of saving prematurely.
- Fixed Kanban drops into **None** storing the literal text rather than clearing the grouping property. List-valued drops preserve existing values when the source column is unknown.
- (#2388) MCP and HTTP queries report invalid properties and incomplete filters rather than successful empty results. Custom-field queries, sorting and grouping accept IDs or frontmatter keys with `user:` or `user.` prefixes. Thanks to @jordankbartos for reporting. See [HTTP API](https://tasknotes.dev/HTTP_API/#post-apitasksquery).
- (#2399, #2377) Fixed Task List crashes when displayed properties or formulas return links, such as `file.backlinks`. Thanks to @ewightman and @Glint-Eye for reporting.
- (#2378) Fixed diagonal Kanban drops leaving the card, cache and other views with the old swimlane value. Thanks to @iantierney for reporting.
- (#2387) Calendar views with **Show hourly breakdown** off now fill the available height and show all all-day events by default. Event-count and row limits are available for these views. Thanks to @etiennejls for reporting. See [Calendar Views](https://tasknotes.dev/views/calendar-views/#view-options).
- (#2397) Reading View no longer renders tags and same-note heading links as task links. Thanks to @hm-24 for reporting and @enieuwy for the fix.
- (#2390) Project selection respects excluded folders, including with project filters. Thanks to @hikatamika for reporting and @enieuwy for proposing a fix.
- (#2382) Existing Bases with settings nested under `options:` or `config:` now retain their Kanban settings, including hidden empty columns and pinned columns. New default Bases write settings directly on each view; existing files remain unchanged. Thanks to @techwiththiru for reporting. See [Kanban View](https://tasknotes.dev/views/kanban-view/#configuration).
- (#2363) Added validation for incomplete property-based task identification and aligned generated Base filters with task lookup. Existing Base filters are not rewritten. Thanks to @cagechi for the report and examples.

## Security

- Updated the MCP SDK and dependencies for published advisories, including Hono's static-path middleware bypass. Added a maintained development-tooling patch that rejects excessive brace-pattern nesting before it can exhaust the JavaScript stack. These updates do not replace libraries supplied by Obsidian itself.
