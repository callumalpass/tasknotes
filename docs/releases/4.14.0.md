# TaskNotes 4.14.0

## Added

- (#2412) Recurring task checkoffs now show the completed occurrence and next date, including the year, with an Undo action. Undo restores the affected occurrence and schedule without overwriting later changes. Thanks to @PaulSnyder for the suggestion. See [Recurring Tasks](https://tasknotes.dev/features/recurring-tasks/#completion-tracking).
- (#2413) Reminders that came due while Obsidian was closed are now shown when it starts, up to 24 hours back. Missed reminders show when they were due, only the latest one per task is shown, and more than three are combined into one summary. Startup catch-up waits for notes still being indexed, and missed-reminder messages are translated into all supported languages. Thanks to @aliceinblunderland0 for the suggestion. See [Task Reminders](https://tasknotes.dev/features/reminders/#delivery-and-sleep).

## Fixed

- (#2411) Google calendars now display user-set names instead of original titles for subscribed and URL-added calendars. Thanks to @Alireza-RS for reporting.

## Security

- Updated the MCP SDK's Hono dependency to fix a published static-path middleware bypass advisory.
