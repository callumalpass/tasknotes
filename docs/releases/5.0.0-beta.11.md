# TaskNotes 5.0.0-beta.11

> [!info] TaskNotes v5 beta
>
> This is an opt-in beta. TaskNotes 4.18.3 remains the recommended stable release.

## Before updating

- Requires Obsidian 1.13.1 or newer. Back up the complete vault and finish syncing before updating. See the [v4 to v5 upgrade guide](https://tasknotes.dev/migration-v4-to-v5/) for metadata upgrades and recovery. Avoid simultaneous metadata upgrades on other devices; TaskNotes App setup still requires its separate consent.
- Before setting up TaskNotes App, update TaskNotes to version 5 on every device that uses the vault. TaskNotes 4 with type definitions turned on can overwrite the v5 task type. Existing vaults keep their type-definition setting; new installs have it on by default.
- This beta includes the stable-release changes through [4.18.3](https://github.com/callumalpass/tasknotes/releases/tag/4.18.3), including the recurring-status fix omitted from beta.10 and the changes from [4.18.0](https://github.com/callumalpass/tasknotes/releases/tag/4.18.0), [4.18.1](https://github.com/callumalpass/tasknotes/releases/tag/4.18.1) and [4.18.2](https://github.com/callumalpass/tasknotes/releases/tag/4.18.2).
- Returning to an earlier beta after updating has not been tested. Restore the pre-update backup rather than relying on a downgrade.

## Added

- Added calendar time slot height and pinch resizing controls, including the height setting in v5's native Calendar defaults page. See [Calendar Settings](https://tasknotes.dev/settings/calendar-settings/).
  - Thanks to @AIDockerCloud for contributing the height setting
- Added **Reset status after each occurrence** in Time & reminders. Existing setups keep their recurring series' status unless this setting is enabled. See [Recurring Tasks](https://tasknotes.dev/features/recurring-tasks/).
  - Thanks to @Pondering-Peregrine for reporting #2521

## Fixed

- Fixed the mobile task composer opening behind the on-screen keyboard. The title, scrollable fields, and save controls now fit above the keyboard.
- Added visible removal actions for nested entries in native list settings, including custom user fields, statuses, priorities, default reminders, calendar subscriptions, and webhooks. Existing confirmation and note-preservation behavior is unchanged.
- (#2119) TaskNotes API tasks and events no longer expose internal Bases data, which could cause circular JSON errors in companion plugins.
  - Thanks to @chrabia for reporting this and @konstantinopolka for finding the cause
- (#2524) Generated Bases formulas use `isEmpty()` so missing time entries show **Not started**. Existing, manually edited Base files are not replaced automatically. See [Default Base Templates](https://tasknotes.dev/views/default-base-templates/).
  - Thanks to @dsebastien for reporting this and proposing the fix
- (#2527, #2528, #2529) Calendar timeblock text remains readable without its colour fill, long titles no longer push the time range outside short timed cards, and back-to-back events are not grouped as overlapping.
  - Thanks to @RumiaKitinari for reporting these issues
- (#2531) Editing a Kanban card preserves the board's horizontal and vertical scroll positions.
  - Thanks to @petrabuchinger2025-code for reporting this
- (#2540) Tasks with only a due date use that date in ICS exports.
  - Thanks to @jayhemnani9910 for contributing the fix
- (#2542) Connected calendar views refresh after event deletion. Google meeting deletion does not send cancellation emails, and recurring deletion affects only the selected occurrence.
  - Thanks to @iantierney for requesting calendar event deletion
- Improved compatibility with Obsidian popout windows for context menus, editor controls, and Kanban drag feedback.
- Fixed tooltip dismissal, Google Calendar visibility refresh checks, and metadata-folder styling in popout windows.
- Metadata folders stay hidden on first launch when a settings popout has focus.
- Removed an iOS-incompatible regular expression from linked-note task conversion while preserving embedded-note handling.

## Changed

- Updated Obsidian plugin guideline checks and included manifest and license validation in the strict lint checks.
- Reduced the plugin download size by compressing bundled release notes; the notes remain available offline and their text is unchanged.

## Security

- Updated Hono and its Node server adapter, used by the MCP SDK, to the security-fixed versions from the stable release.
