# TaskNotes 5.0.5

## Fixed

- (#2677) Restored drag-and-drop reordering for task statuses and priorities in Properties settings. Thanks to @hikatamika for reporting.
- (#2106) Open calendars that use the global first-day-of-week setting now update as soon as it changes. Thanks to @atos2212-blip, @leon-adsk, @cweekly, @idontcode34 and @hikatamika for reporting and helping diagnose the issue.
- Improved recovery when an interrupted mdbase v0.2 to v0.3 metadata upgrade leaves a pending recovery record and rollback is blocked by a changed metadata file. TaskNotes now shows a startup notice and adds persistent recovery controls under **Settings → TaskNotes → TaskNotes App** to either keep current files and resume sync or restore the verified v0.2 backup while keeping backup folders intact.
- (#2694) Fixed overlapping and misaligned icons in the task creation and editing dialogs when Media DB is enabled. Thanks to @techy-robot for reporting.
- (#2702) Google, Outlook and Yahoo calendar links now place due-only tasks on their due date and treat date-only tasks as all-day events. Thanks to @jayhemnani9910 for the fix.
