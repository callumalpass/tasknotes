# TaskNotes 5.0.0-beta.13

> [!info] TaskNotes v5 beta
>
> This is an opt-in beta. TaskNotes 4.18.4 remains the recommended stable release.

## Before updating

- Requires Obsidian 1.13.1 or newer. Back up the complete vault and finish syncing before updating. See the [v4 to v5 upgrade guide](https://tasknotes.dev/migration-v4-to-v5/) for metadata upgrades and recovery. Avoid simultaneous metadata upgrades on other devices; TaskNotes App setup still requires its separate consent.
- Before setting up TaskNotes App, update TaskNotes to version 5 on every device that uses the vault. TaskNotes 4 with type definitions turned on can overwrite the v5 task type. Existing vaults keep their type-definition setting; new installs have it on by default.
- Returning to an earlier beta after updating has not been tested. Restore the pre-update backup rather than relying on a downgrade.

The following changes are new since [5.0.0-beta.12](https://github.com/callumalpass/tasknotes/releases/tag/5.0.0-beta.12).

## Changed

- TaskNotes adds less time to Obsidian startup. Bundled interface translations are now decoded only for English and the language in use, instead of for all ten languages, each time the plugin loads.
  - Less work runs just after the workspace opens. The reminder check reads only tasks that have reminders; the default Bases view files are no longer regenerated when they already exist; and the task index warmup runs when Obsidian is idle instead of during startup.
  - Background setup is lighter. Daily notes are listed for Google Calendar timeblock sync only when timeblock sync is on, and tasks are no longer all loaded up front to detect direct edits to task files; each task's earlier state is read only when it is edited.
