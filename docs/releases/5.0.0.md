# TaskNotes 5.0.0

## What's new

- **TaskNotes App**: use your vault's tasks on the [web](https://app.tasknotes.dev/), [iPhone](https://apps.apple.com/app/tasknotes/id6797168033) and [Android](https://play.google.com/store/apps/details?id=dev.tasknotes.app). See [Use TaskNotes App with your vault](https://tasknotes.dev/guides/tasknotes-app/) to set it up.
- **A redesigned interface** for task lists, boards, calendars, pickers and task dialogs, closer to Obsidian and your theme.
- **Native settings**: TaskNotes settings use Obsidian's settings pages and search.
- **Sign in with Google** for Google Calendar, without setting up a Google Cloud project.
- **Keyboard navigation** in Task List, Kanban and calendar views.
- **Stable task IDs** that stay the same when a task is renamed or moved.

These notes cover changes since 4.18.4. The 5.0 beta release notes have the full history.

## Before updating

- TaskNotes 5 requires Obsidian 1.13.1 or newer.
- Update TaskNotes on every device that shares the vault, since TaskNotes 4 and 5 store some settings differently.
- Your task notes aren't changed by the update, and existing Base files stay as they are. As with any major update, it's a good idea to back up your vault first; to go back to 4.x, restore that backup.
- The [v4 to v5 upgrade guide](https://tasknotes.dev/migration-v4-to-v5/) covers what changes in more detail.

## Added

- Added a **TaskNotes App** settings page with links to the app and the steps to use it with your vault. **Generate mdbase type definitions** is now **Turn on type definitions**: on by default for new installs, unchanged for existing vaults. Existing TaskNotes mdbase metadata is upgraded automatically, with a backup in `.tasknotes/migrations/`. See [mdbase collections](https://tasknotes.dev/migration-v4-to-v5/#mdbase-collections).
- Added **TaskNotes: Check collection**, which lists task notes that don't match the task type and can fix missing creation dates and unknown statuses after you confirm.
- Added **Sign in with Google** under **Settings → TaskNotes → Calendars & integrations → Google Calendar** to see, create and edit Google Calendar events. Exporting tasks and timeblocks still uses your own Google Cloud project. See [Calendar Integration](https://tasknotes.dev/features/calendar-integration/).
- Task List, Kanban and calendar views can be used from the keyboard. Move between tasks with the arrow keys or J/K, select with X or Shift+arrow, and change status, priority, due date, scheduled date or tags with S, P, D, Shift+H or T, for one task or the whole selection. E edits, Enter opens, C creates, / searches, Mod+K opens the actions palette and Mod+Z undoes. Press **?** in a view for all shortcuts. See [Keyboard shortcuts](https://tasknotes.dev/views/#keyboard-shortcuts).
- New and converted tasks get a UUID in the `id` property. Existing tasks are unchanged. The JavaScript API adds `getByPath()` and `getById()`. See [JavaScript API](https://tasknotes.dev/javascript-api/).
- Tasks can list attachments in an `attachments` frontmatter property.
- Added **Today** and **Inbox** commands. Newly generated default Bases include Inbox and Archived views.
- (#2354) Added a date format setting for ISO 8601 dates under **Appearance & interaction → Display formatting**. Thanks to @spozzi99 for requesting this.
- (#2126, #2134) Added filename templates for recurring occurrence notes. See [Recurring Tasks](https://tasknotes.dev/features/recurring-tasks/#occurrence-filenames). Thanks to @raphaelfaouakhiri for reporting and implementing this.
- (#2105) Added `{{projectFolder}}` and `{{projectFolders}}` folder template variables. See [Template Variables](https://tasknotes.dev/features/template-variables/). Thanks to @carypruitt for this contribution.
- (#2142) The MCP `tasknotes_create_task` and `tasknotes_update_task` tools accept `customProperties`. Thanks to @phillipadsmith for suggesting this.
- (#2436) Added **Use default projects only when no project is specified** under **Task creation → Defaults**. When it's on, a project you pick or type while creating a task replaces your default projects instead of being added to them. Off by default. See [Task Properties](https://tasknotes.dev/settings/task-properties/). Thanks to @RumiaKitinari for the request.
- (#1147) The Pomodoro view lists your recent work sessions, and you can delete a session recorded by mistake, such as one left running overnight. See [Pomodoro View](https://tasknotes.dev/views/pomodoro-view/#recent-sessions). Thanks to @RumiaKitinari for reporting and @BrucePlumb for the follow-up.
- **TaskNotes: Open Pomodoro statistics** opens a generated Pomodoro statistics Base with daily and monthly totals of Pomodoros, focus time and breaks, from sessions stored in daily notes. See [Pomodoro statistics Base](https://tasknotes.dev/features/time-management/#pomodoro-statistics-base).
- The **Icon** field for statuses and priorities suggests Lucide icons as you type.
- Timeblocks and non-task notes have their own right-click menus in TaskNotes views and the calendar.

## Changed

- Settings use Obsidian's native settings pages and search, regrouped into Task files, Properties, Task creation, Appearance & interaction, Time & reminders, Calendars & integrations, TaskNotes App and Advanced. See [Settings](https://tasknotes.dev/settings/).
- Task lists, boards, calendars, pickers and task dialogs take their spacing, type, colours and controls from Obsidian and your theme. Rows and cards are more compact, priorities show as a coloured dot at the end of the title line, and dates within a week show as relative days, such as "Due: Yesterday". Dragging a task shows a small chip that says what dropping it will do.
- Status, priority, dates, recurrence, reminders and tags open the same searchable picker everywhere, including in right-click menus.
- Deleting a task, note or timeblock happens straight away, with **Undo** in the notice that follows.
- The calendar uses TaskNotes' own engine instead of FullCalendar. Existing calendar settings keep working. Month views can show a selected-day panel, and agenda views have a date strip.
- The create and edit task dialogs share one layout, with a Markdown title editor and **More fields** for the rest. On mobile, the dialog stays above the keyboard.
- Natural language tags, contexts, projects and custom fields need a space before them, so email addresses and URLs stay intact.
- (#2032) On mobile, list reorder handles support long-press dragging. Thanks to @spasche for reporting.
- TaskNotes no longer creates a Start Here note on first install. Open it with the **Open the Start Here guide** command.
- New installs store Pomodoro sessions in daily notes instead of `data.json`. If the day's note can't be created, the session is saved to `data.json` instead. Existing setups keep their current storage. See [Recorded data](https://tasknotes.dev/features/time-management/#recorded-data).
- Boards in a note's relationships panel show only the columns that have tasks.
- TaskNotes starts faster and the plugin download is smaller.

## Removed

- Removed the Statistics and Pomodoro statistics dashboards, and the **Open task & project statistics** command. **Open Pomodoro statistics** opens the new Pomodoro statistics Base instead. The Pomodoro timer, time tracking and recorded sessions are kept. To total tracked time by project, see [Time by project with Bases](https://tasknotes.dev/features/time-management/#time-by-project-with-bases).
- (#2550) Removed settings that had no effect: **Disable note indexing**, **Enable fuzzy matching**, **Show due dates when scheduled** and **Show ICS events**.
- Removed **Export v3 saved views to Bases**. To convert v3 saved views, run the export in TaskNotes 4.x first.
