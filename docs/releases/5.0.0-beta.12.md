# TaskNotes 5.0.0-beta.12

> [!info] TaskNotes v5 beta
>
> This is an opt-in beta. TaskNotes 4.18.4 remains the recommended stable release.

## Before updating

- Requires Obsidian 1.13.1 or newer. Back up the complete vault and finish syncing before updating. See the [v4 to v5 upgrade guide](https://tasknotes.dev/migration-v4-to-v5/) for metadata upgrades and recovery. Avoid simultaneous metadata upgrades on other devices; TaskNotes App setup still requires its separate consent.
- Before setting up TaskNotes App, update TaskNotes to version 5 on every device that uses the vault. TaskNotes 4 with type definitions turned on can overwrite the v5 task type. Existing vaults keep their type-definition setting; new installs have it on by default.
- Returning to an earlier beta after updating has not been tested. Restore the pre-update backup rather than relying on a downgrade.

The following changes are new since [5.0.0-beta.11](https://github.com/callumalpass/tasknotes/releases/tag/5.0.0-beta.11).

## Fixed

- Fixed Google and Microsoft calendar event titles running underneath the calendar icon in the top-right corner of short events.

## Changed

- Updated TaskNotes App setup instructions to offer either the mdbase desktop app or the Obsidian sync plugin, with direct links to both. See [Use TaskNotes App with your vault](https://tasknotes.dev/guides/tasknotes-app/).
- Task card titles now use regular weight instead of medium, so task lists, Kanban boards and calendar list views read lighter. The smaller, muted metadata line still sets each title apart.
