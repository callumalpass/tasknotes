# TaskNotes 4.13.10

## Added

- (#2404) Added an opt-in **Enter saves task** setting for the task creation window's natural language input. Shift+Enter still inserts a newline and Ctrl/Cmd+Enter still saves. Enter accepts a visible autocomplete suggestion instead of saving and does not save while confirming IME text. See [Natural Language Processing](https://tasknotes.dev/settings/features/#natural-language-processing). Thanks to @k4zcho for contributing this.

## Changed

- (#2381) Task List group and subgroup moves no longer require manual-order sorting. Drops preview property changes, reordering has a separate insertion line, and the movement handle provides a destination menu and manual-order **Move up/down** actions. Property moves offer Undo while preserving later unrelated edits. A separate **Add as subtask** target preserves existing project memberships, group values, and manual rank; self-assignment and cycles are blocked. List-valued moves show the full before/after values, and dropping on the original row cancels the move. See [Task List](https://tasknotes.dev/views/task-list/). Thanks to @iantierney for the suggestion.

## Fixed

- (#2328) Fixed completing or skipping an occurrence note of a recurring task scheduled with a time (such as 09:00) not recording the date on the recurring task or moving it to the next occurrence. It failed whether the status was changed in Properties, on the task card, or by another plugin. Thanks to @mudnug for reporting this and following up.
- (#2409) Fixed recorded time entries disappearing from the calendar when they continue into a new week or other visible date range. Thanks to @RumiaKitinari for reporting this.
- Fixed status autocomplete suggestions being hidden by the editor's automatically paired closing `*`, so Enter can select the suggested status instead of saving prematurely.
- (#2408) Localized Modal Fields controls, labels, type badges, notices, and reset confirmation. Saved field and group names remain unchanged. Thanks to @whysoslow for contributing this fix.
- Kanban drops into the empty **None** column now clear the grouping property rather than storing the text "None". List-valued drops preserve the existing list when the source column is unknown.
- Fixed manual reordering in descending Task List and Kanban views when a group contains only one other task.

## Security

- Updated the MCP SDK and dependencies to address published security advisories. Added a maintained development-tooling patch that rejects excessive brace-pattern nesting before it can exhaust the JavaScript stack. These updates do not replace libraries supplied by Obsidian itself.
