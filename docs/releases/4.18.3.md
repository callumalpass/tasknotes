# TaskNotes 4.18.3

## Added

- (#2542) Google and Microsoft calendar events shown in TaskNotes calendar views can now be deleted from their right-click menu, after a confirmation. For a recurring event, only the clicked occurrence is deleted. The option is not shown for ICS subscriptions or calendars marked read-only by the provider. See [Calendar Integration](https://tasknotes.dev/features/calendar-integration/#synchronization-behavior).
  - Thanks to @iantierney for the request
  - Deleting a Google meeting does not send cancellation emails to guests. There is no whole-series deletion option.

## Fixed

- Calendar and mini-calendar views now refresh when connected calendar providers change, so deleted events do not remain visible in list and mini-calendar views.

## Security

- Updated Hono and its Node server adapter, dependencies of the MCP SDK, to versions with security fixes.
